## 1. What it is, state, layout
- Playable MIDI instrument for the Amorph host: 8 voices; each = exciter (hammer/bow/breath/particles/grains/pluck) -> stiff string pair <-> 3-port bridge <-> morphable 16-mode modal "body", plus STK banded WG, 2D mesh and reed/flute/brass/whistle/bottle bores. Global: self-granulation cloud, plate+spring space, 8 sympathetic loops, Larsen "Sing" loop with optional Kelly-Lochbaum vocal tract, tape, master sat. Goal is abstract/ambient texture ("no realism contest", KONZEPT s1), so the "body" is 4 abstract archetypes (bar/membrane/plate/bell), **not** instrument bodies.
- **State per docs:** M0-M7 done, CHECKLISTE_SOLL_IST "0 open points", CODE_AUDIT G1-G19 all closed (docs/CHECKLISTE_SOLL_IST.md:4,128-141). Never loaded in Amorph; UI only `node --check`ed (CHECKLISTE F4); OFFENE_PUNKTE.md #1 = first real play test + CPU check.
- **CPU:** budget "<15 % of one core" (KONZEPT.md:94), granular <=5 % (:122). Only measured: bare modal bank (m0/BENCH.md, cmaj 1.0.3175 JIT, 4-core container): 512 modes@48k 0.48 % core (207x RT), 256 modes 0.23 %, 64 modes 0.10 %, 512@96k 3.45 %, 8 voices x 512 ~ 3.8 %. **No whole-plugin CPU figure exists in the repo -> "budget met" is unproven.** The plugin only runs 16 modes/voice.
- **Layout:** `plugin/` (Physify.cmajorpatch 12 lines, DSP, CORE, UI, analyze.py, demo wavs) - `plugin_tests.cmajtest` - `m0/` (spike: patch/, bench/ModalBench.cmajor.template + run_bench.sh, tests/M0.cmajtest, BENCH.md) - `tools/` (golden_ci.py, golden_ref.json, lhs_fuzz.py, bowlab.py) - `docs/` (KONZEPT 284 lines, CODE_AUDIT, CHECKLISTE_SOLL_IST, OFFENE_PUNKTE, research/01-15) - `demos/`.
- **Architecture caveat for reuse:** ONE monolithic `processor Physify [[main]]` (DSP:14), no graph, no sub-processors. Only governor/RNG/morph tables/MeterFrame are in `namespace physify` (CORE). All voice DSP is inline in `main()` (DSP:2014-3062) and the `Voice` struct (DSP:226-301) => reuse means copy/extract, not import. No oversampling (decision G1, measured), state is float32 (`float<8>[2] bu,bv` DSP:280; coefficients computed in float64 then cast).

## 5. Research findings relevant to body resonance / vocal tract (06, 09, 15, +07)
- 06 s9 Membrane+air: kettle air load pulls (1,1),(2,1),(3,1) to near-harmonic; tabla = density loading. Cheap recipe: retuned modal membrane table + one Helmholtz/cavity oscillator coupled **bidirectionally** (must be passive) + tension-modulation glide. CPU cheap.
- 06 s5 Vocal tract: ~44-section KL ladder is trivial CPU and passive while |K|<1 and terminations abs(r)<1; LF glottal source is feed-forward/safe, two-mass folds add oscillator risk; nasal branch + lip radiation matter more for realism than stability; 2D cross-modes >~5 kHz are 1D-model limits; sndkit `tract` (C, permissive) and Pink Trombone are references; commercially open (also 02 s4.7).
- 15: Fant 1960 area functions /a i u/ at 0.5 cm segments (17.5/17/20 cm; c=35400 cm/s) and formant targets (Titze benchmarks); our KL port hits F1/F2 within ~6 % (research/15:65-81).
- 06 s4 Woodwinds: single reed = pressure-controlled memoryless valve; double reed adds flow-separation asymmetry; cylinder (odd harmonics, 12th) vs cone (full series); tone-hole lattice cutoff defines the instrument "formant"; **conical-junction growing-exponential instability**; parameter interpolation during fingering changes can blow up; reed beating needs a collision model.
- 06 s3/s11: lip/valve = stiff nonlinear oscillator in a delay loop (blow-up territory; steepening needs oversampling); contact chatter -> aliasing; implicit/energy-stable schemes exist.
- 06 s7 String networks: bridge feedback matrix must be passive; frequency-dependent bridge phase error grows energy only after seconds -> test long sustains. 04 B1-B4 (same repo): shared-termination filter coupling + gain-matrix with governor; two-way only for string<->body, exciter<->resonator.
- 06 s6 Plates/shells: linear banks never give "bloom"; von-Karman is expensive, phenomenological mode coupling is the cheap steerable path (PHYSIFY uses NL-warble + switching allpass instead).
- 06 shortlist: pattern [exciter] -> [nonlinear contact/friction] -> [linear resonator network]; adopt energy-stable/port-Hamiltonian principles for anything nonlinear.
- 09 A2/A3: modal = SVF or coupled-form, never direct form; coefficients float64, float64 state for <~200 Hz; allpass for static tuning only. 09 A9: fixed internal core rate (nonlinear loops alias differently per fs).
- 07 (outside 06/09/15 but decisive): define the **mode-table + exciter-sample file format first**; capture/mesh-to-modes are offline producers feeding a dumb fast Cmajor consumer.

## 7. Pitfalls and Cmajor hurdles (09, CODE_AUDIT, CHECKLISTE)
- Morph + recursive filters: coupled-form/SVF only, per-sample ramps (PHYSIFY: 10-ms one-poles, click -61 -> -116 dB, CHECKLISTE G2); stdlib filters update on events without ramping (09 A2).
- In-loop aliasing: only oversampling is general (09 A1). PHYSIFY measured and **skipped** 2x (alias lines -42..-58 dB relative, only extreme pitch+Grit; regression gate "alias > -40 dB => re-decide", CHECKLISTE G1). A body model with bore/reed loops must re-measure.
- "Governor != stability": loop gain < 1 by construction (row-sum rule, passivity bound abs(rho)<=0.99); ungoverned x40 gain self-oscillated (BENCH.md).
- Euler chatter on stiff contact -> 4x substepping (CODE_AUDIT G1); one-sided nonlinearities/force pulses inject DC -> DC block after the NL, keytracked pole to avoid sub-sonic resonance (CORE:43-53); KS loops without DC block need alternating-sign bursts (CHECKLISTE E2/I6).
- Fractional delay: Lagrange-3 for anything gliding, Thiran only static; dispersion allpass phase delay must be subtracted from loop length (+26 ct error otherwise, DSP:~812-846); per-register tuning LUT (`tuneCorr` DSP:590-604) needed.
- Sample-rate identity: loop-LP coefficient a48^(48000/sr) (root cause of a tri-rate error, mis-diagnosed first); STK per-sample constants (Mesh2D/Whistle/Rattle) not fs-normalised; tract `N` clamp 64 breaks >~60 kHz; tri-rate CI covers only hammer+bow.
- Measurement contamination: apparent detune came from the plate grid/Glow/body - measure with Space/Glow/Cloud/Body Mix = 0 (DSP:581-589 comment). Calibrate then verify with LUFS gate; do not tune "by feel" (CODE_AUDIT rule).
- Cmajor limits (09 B): no public delay-line/Lagrange/junction in stdlib, no `switch`, static arrays only, large inline literals fail (#135) -> use flat `external` arrays; slow C++ export with big externals (#103); multi-dim struct arrays bug (#94); keep graphs coarse (#44) and put scale inside processors as `float<8>` vectors; `cmaj render` aborts on value-array endpoints (PHYSIFY uses event arrays, CHECKLISTE E6).
- Denormals: FTZ in JIT/native, **none in WASM**; PHYSIFY has no ~1e-20 dither (grep: none) - add if WASM matters (09 A3).
- Tooling periphery is the weak side (09): Linux WebView/GUI issues, DAW quirks, no debugger; UI never WebView-tested; CC1/CC-learn write `pMorphY` directly (:1668-1672) and fight host automation of param 8.
