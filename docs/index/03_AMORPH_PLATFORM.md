## 2. Hard rules for an FX plugin
**2a Cmajor subset (A:context-src/v1/dsp/fx.md unless noted)**
- Never name anything `input`/`output`/`stream` (:8; display label `"Output"` is fine, id `outGain`). Helpers only at processor scope, never in `main()`/handlers (:9).
- No `double` (use `float64`, phase accumulators `float64`); `sin/cos/tan/tanh/sqrt/pow/exp/log` return `float64` -> wrap in `float(...)` (:11,13). No `auto, unsigned, uint32_t, uint64_t, size_t, constexpr, static`, no local `State& s` aliases; ASCII ids (:12). No `Math.`, `processor.currentTime`, `uint` (core-dsp-foundations.md:59). Float `%` invalid -> `fmod` (:63). `select()` vector-only; scalars use `cond ? a : b` (:4).
- **No `let` anywhere in generated source - typed locals only** (:25,92; A:CMAJOR_QUICKREF.md:107). NOTE: upstream's own LANG_REF_FX examples (:97,171+) and every B example use `let`.
- Fixed-size arrays, `.at(i)`, no runtime sizing (:22); struct fields are declarations only, init in `main()` (:33); only `namespace/processor/graph` at file top (:80); `external` cannot be initialised (core-dsp:61).
- `main()` has a continuous `loop`, writes `out <- float<2>(L,R);` and calls exactly one `advance()` per iteration; DSP only in `main()`, handlers just set targets (:23,90). Read frame as `float<2> inputFrame = in;` index `[0]/[1]` (:10).
- `processor.period` only as `float(processor.period)` (:27); every `/` and `%` divisor provably nonzero, lint is syntax-based (:28).
**2b Sample rate / state / denormals / CPU**
- Rate from `processor.frequency` (float64), clamp cutoffs to `0.45*sr` (core-dsp:10,72); sample-rate-independent coefficients (:74-80); never hardcode 44100/48000 (B:docs/02:78-83; B:tools/cmajor_lint.py:45). Inside `* N` nodes `processor.frequency` reports the oversampled rate (B:docs/06:47-49). QA renders at 44.1 kHz (A:README.md:30); kit release test 44.1/48/96 kHz (B:docs/09:87).
- Delay buffers sized for the max delay at the HIGHEST sample rate or cap the endpoint max; clamp reads `1..N-1`, interpolate, feedback strictly < 1 (fx.md:54-58). No runtime buffer resize (core-dsp:114-115).
- State/reset: upstream documents NO reset hook. Create stdlib filter objects once at `main()` start (core-dsp:35-44); init struct instances in `main()` (fx.md:33); a Cmajor state initialiser is not a substitute for annotated `init` (fx.md:21). Smooth cutoff/gain/mix/pan/drive/delay/feedback via `std::smoothing::SmoothedValue` or one-pole (core-dsp:82-84).
- Denormals: upstream silent; kit: tiny floor / `flushDenormal` in feedback tails (B:docs/02:57-58; B:docs/11:116-118; cookbook #14). DC: `dcblocker` after nonlinear/asymmetric stages (fx.md:50).
- CPU: **no numeric CPU budget in either repo.** Only: total fixed delay state for a multi-stage reverb ~<= 131072 floats; 65536 per comb/allpass can stall the host compile (core-dsp:157-160). Kit: oversample only harmonic-generating stages, hoist coefficients, `.at(i)` indexing (B:docs/06:144-152; B:docs/11:102-118); `* N` latency ~3/5/6/6 samples for 2/4/8/16x (B:docs/06:84-93).
**2c Audio behaviour gated by `run_qa_probe`** (440 Hz sine, 32x512 blocks @44.1k; RMS, peak, NaN/Inf, silence, clipping, DC, stereo corr/width, phase cancel: A:README.md:30)
- Stereo integrity: preserve dry image, distinct L/R wet state (fx.md:29); reverb/delay/chorus/spatial must be audibly wet within 2 s at defaults with an early wet branch < ~250 ms (fx.md:30); `0 dB` = unity, defaults unclipped (fx.md:96); equal-power mix law (core-dsp:140-145); true-Q TPT SVF, never a 0..1 knob into Q (core-dsp:35-53).
- **Modal/physical resonator** (relevant to a body model): inharmonic modes, unequal frequency-dependent damping; per-row feedback sum(|weights|) <= 0.98 (safe `0.94*own+0.02*other`; `0.997/0.018` unsafe); no tanh/clamp to excuse over-unity; DC-block each final wet channel with independent state; probe impulse + zero-mean noise at default and extreme damping; require un-clamped finite decay and `|DC| < 0.01` (core-dsp:116-133).
**2d UI contract** (A:context-src/v1/shared/core-ui-contract.md + UI_REF_FX.md:32-126)
- Plain ES6 + Web Components, no framework/import/remote asset; light DOM only (`this.innerHTML`, never `attachShadow`); exactly one `HTMLElement` subclass; define element once via `customElements.get` guard (core-ui:8-21,81).
- One `.control[data-param="paramN"]` per parameter with `data-min/max/init(/mid/step)/control`, never repeated on descendants; nonzero geometry + visible widget; controls in a `Map` (core-ui:27-37; `run_ui_probe` audits `[data-param]`, A:TOOLS.md:56). Continuous = dial/slider; discrete/enum/on-off = real `<button type="button">`/segmented/toggle/select (core-ui:38-40).
- Pointer events on the ELEMENT with `setPointerCapture` + `preventDefault`, `dblclick` reset, vertical drag, Shift = fine; never window/document listeners (core-ui:44-52; UI_REF_FX.md:55-61). `mid` mapping `power = ln((mid-min)/(max-min))/ln(.5)`; never `skew` (core-ui:54-58). `setValue(v, notify)` clamps+quantises, paints label, notifies host only if `notify===true`; init `setValue(init,false)`; labels start as `--` (core-ui:51-53; UI_REF_FX.md:420-421).
- Order: build controls -> register `addAllParameterListener` -> `requestParameterValue` for each; remove listeners/animation/pointer capture in `disconnectedCallback` (core-ui:67-77; UI_REF_FX.md:114-119). Paint readouts in `setValue`, not only rAF (rAF is throttled in background; UI_REF_FX.md:420).
- Layout: first CSS `* {box-sizing:border-box;margin:0;padding:0} body,html{overflow:hidden;margin:0}`; `:host, .patch-root {display:block;width:100%;height:100%;overflow:hidden}` + `classList.add("patch-root")` (":host alone is dead in light DOM"); no fixed px on host/containers, `%/fr/flex/grid` only, no scrolling containers, `user-select:none` (UI_REF_FX.md:95-104; core-ui:79-91).
- Canvas: size once in `connectedCallback` from `offsetWidth/Height`; never in rAF; no `height:100%` on a grid/flex-item canvas without `min-height:0` (use wrapper + `position:absolute; inset:0`); store/cancel rAF handle. **ResizeObserver: banned by v1 (core-ui:98), allowed by paste UI_REF (UI_REF_FX.md:108)** (:93-101; UI_REF_FX.md:106-112).
- Kit WebView lessons [field-tested]: no `backdrop-filter`, no `vw/vh`, escape backticks/backslashes in template literals, pause hidden CSS animations, no web fonts/CDN/web access, `localStorage` only for UI-only conveniences (B:docs/05:37-62,71-98; B:docs/03:122-140).
**2e Accessibility**: only ARIA slider role with min/max/label/current value on drag controls (core-ui:50), real buttons for discrete states (:38-40), optional keyboard Enter/Space/Arrows (UI_REF_FX.md:67), readable distinct controls (core-ui:90). No contrast/WCAG/focus requirement exists in A or B.
