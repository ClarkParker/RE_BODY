## Owner questions (coarse, each with recommendation)
- **Q1 Chassis.** 720 × 540 so the field keeps ≥ 200 px (BODY's own large layout gives 199 px), or 720 × 460 with the strips beside the deck? Recommendation: 720 × 540.
- **Q2 Material in the main deck** (Tune, Decay, Material, Mix) or BODY's original deck (Tune, Decay, Mix) with Material in the strip? Recommendation: main deck, it is the one axis every professional body plugin exposes.
- **Q3 Classic view** as a *skin* (original 1 px rail, original dial look, flat field, all controls stay visible) instead of hiding controls? Recommendation: yes, skin.
- **Q4 Motion budget.** Research says tilt ≤ 2° and no idle motion; LALAFY used far more. Proposal: Motion Calm = tilt 1.5°, audio motion on, no idle drift; Full = tilt 4°, idle drift ±1°; Off = static depth. Default Calm (D17). OK?
- **Q5 Lines B/C presentation** depends on the host spike: if hidden controls fail the probe, B and C get a compact always-visible strip instead of tabs. Accept that fallback in advance?
